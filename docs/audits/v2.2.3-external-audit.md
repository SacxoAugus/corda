## Achados verificados

### Atestado na fronteira

`compare_observers` foi atacado por chamada direta com 14 variantes. Somente o
atestado completo, com par correto, status verificado, método permitido,
verificador, data e origem, produziu `corroborating`.

### Integridade de hash inline

O validador:

- aceitou hash correto;
- rejeitou hash divergente do conteúdo;
- rejeitou formato inválido;
- aplicou a normalização declarada;
- falhou antes do preflight.

O teste detecta hash declarado incompatível; não detecta uma colisão
criptográfica real.

### Benchmark

O contrato continha nove inputs, nove ground truths e três holdouts ortogonais.
As métricas reportadas foram:

| Métrica | Baseline v2.2.1 | Candidata v2.2.3 |
| --- | ---: | ---: |
| aplicabilidade | 0,6667 | 1,0000 |
| false-open | 0,4286 | 0,0000 |
| invariantes | 0,7719 | 1,0000 |

O baseline estático foi reexecutado com o compilador preservado; 9/9 registros
foram reproduzidos.

### Independência de grafo

Uma narrativa longa sem artefato visual produziu `COMPILE_RUNTIME`. O grafo
permaneceu opcional.

## Limite inferencial

O relatório foi explícito: nove casos autorais demonstram conformidade nesses
casos, não generalização. A derivação de elenco adicionada na v3 não fazia parte
desta auditoria e permanece candidata.
