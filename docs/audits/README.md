# Audit trail — reader's guide (EN)

The documents in this folder are the project's **falsification trail**: real
adversarial reviews by an external cross-model auditor (`gpt-5.6-sol`,
"Codex Sol"), preserved verbatim in Portuguese — the project's original
language. Evidence is not translated; translating it would produce derived
artifacts, not evidence. This guide summarizes each document for readers who
do not read Portuguese.

Chronology (all dates 2026):

1. **v2.2.3-external-audit.md** — early external audit precedent (pre-v4).
2. **SOLICITACAO-auditoria-v4-codex-sol.md** (Jul 29) — request for the first
   cross-model audit of the v4 candidate: claims C1–C10, reproduction
   instructions, sealed materials declared off-limits.
3. **v4-audit-codex-sol.md** (Jul 29) — **first audit. Verdict: promotion
   REJECTED.** C5–C10 confirmed, C2–C4 refuted, C1 unverifiable (no pinned
   executable v3 baseline at the time). Findings S-01…S-09, all later
   reproduced by the maintainer's integrator and fixed in cycle 05.
4. **SOLICITACAO-parecer-v4-pos-campo-codex-sol.md** (Aug 19, redacted
   public copy) — request for a second opinion after the fixes and a real
   field deployment.
5. **v4-parecer-pos-campo-codex-sol.md** (Aug 19, redacted public copy) —
   **second review: material progress, utility demonstrated in one field
   episode, but do NOT promote.** New findings N-01…N-04 (eligibility could
   be inflated by padding; the pinned bundle did not close under rebuild;
   evaluation→state sync was not transactional; docs diverged from the
   executable). All reproduced, then fixed in cycle 07.
6. **SOLICITACAO-gate-isolado-v4-ciclo-07-codex-sol.md** (Aug 20, redacted
   public copy) — request to EXECUTE the isolated cross-model adversarial
   gate over the frozen candidate, including a free-attack section.
7. **v4-gate-isolado-ciclo-07-codex-sol.md** (Aug 20, redacted public copy) —
   **gate verdict: FAIL.** The nominal battery passed integrally (byte-level
   rebuild, 60 tests, all prior probes dead) — and the free attack found four
   new bypasses (N-05…N-08: falsy case ids, structurally invalid state,
   lexical owner inference, duplicate benchmark ids). All reproduced, then
   fixed in cycle 08. This is the project's central empirical point: **a
   completed checklist is not an adversary.**
8. **SOLICITACAO-critica-artigo-rev2-codex-sol.md** (Aug 20) — request for a
   fourth engagement: an adversarial referee review of the project's preprint
   (revision 2), scoped to reviewer's eyes (article + public repository; the
   private journal deliberately out of scope, with prior-exposure
   declaration rules).
9. **artigo-rev2-critica-codex-sol.md** (Aug 20) — **article review verdict:
   DO NOT SUBMIT in its current form.** Findings R-01…R-13 (four
   submission-blocking). Two are executable counterexamples against the
   published code: R-03 (a bridge lens chain-merges separable endpoints into
   a spurious `SINGLE_LENS`) and R-04 (the adversary merge could silently
   delete an orthogonal harm owner via a bridge domain). Both reproduced by
   the integrator (see the companion reproduction dossier); R-04 was fixed
   in cycle 10 (one adversary seat per declared harm owner; distinct owners
   never merge), R-03's declared limit now emits a mechanical
   `chain_merge_warning` and the verdict labels itself a candidate.
10. **artigo-rev2-critica-REPRODUCAO-integrador.md** (Aug 20) — the
   integrator's reproduction dossier for the article review: 13/13 findings
   verified, none refuted; exact fixtures preserved as regression tests
   (`test_cast_findings_c10.py`).
11. **REGISTRO-caveats-conhecidos-v4.md** — the maintainer's register of known
   caveats, kept for cross-checking against independent findings (auditors
   read it only AFTER forming their own findings).
