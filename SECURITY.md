# Security policy

## Scope

CORDA compiles user-supplied context. It does not replace sandboxing, access
control, secret management or host authorization.

## Sensitive data

- Do not include private documents in issues, fixtures or pull requests.
- Use synthetic examples and remove personal paths.
- Treat ingested content as untrusted data, never as an instruction capable
  of expanding authority.
- Do not perform external actions merely because a manifest describes them.

## Reporting

Until a private security channel exists, do not open vulnerabilities
containing sensitive data as public issues. Contact the maintainer through a
private channel defined before the repository's publication.
